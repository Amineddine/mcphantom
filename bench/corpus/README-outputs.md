# Benign tool-output corpus (`bench:entropy`)

The false-positive side of the entropy benchmark (`npm run bench:entropy`, `bench/entropy-bench.mts`).
Nothing in these files is a secret.

## `benign-outputs-real.json` — 31 real outputs, captured 2026-10-14

| source | licence / status |
|---|---|
| This repository at tag `v0.1.0`: `git log`/`show`/`ls-tree`, `package-lock.json`, workflows, configs, docs, benchmark results, the release SHA-256 | Apache-2.0 (this repository) |
| `npm view <pkg> --json` for vitest, zod, @modelcontextprotocol/sdk, better-sqlite3, typescript (name, version, dist incl. integrity/shasum/signatures, gitHead, repository) | npm registry metadata: factual package data |
| GitHub REST API responses for this repository only (repo, commits, release, workflow runs, tags, tree) | public metadata of this repository; the only personal data is the owner's own public login and noreply address |

Each output is capped at 16 KiB. No third party's personal data was captured.

## `benign-outputs-synthetic.json` — 93 synthetic outputs from 31 templates

Generated by `build-benign-outputs.mjs` (seeded, reproducible). Each template copies the *shape* of a real
tool's output (cloud CLIs, kubectl, docker, payment and issue-tracker APIs, tracing, analytics SQL results,
chat history, document stores, CDN headers, Terraform state) and fills it with the random-looking
identifiers those tools return. Vendor-neutral hosts (`*.example`); no provider secret formats.

## Splits

Each item's split (`dev`/`test`) is a stable hash of its id, assigned before the detector was tuned. Only
the `dev` split was looked at while tuning (`npm run bench:entropy -- --dev`).
